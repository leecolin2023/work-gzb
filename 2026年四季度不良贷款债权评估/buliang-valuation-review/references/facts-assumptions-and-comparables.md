# 事实、假设及可比案例核验

## 一、四方事实核对

固定母项F01~F10维持不变，以下子项按实际适用性逐项处理。它们不会被40项母项的完成记录替代。

| 编号 | 问题 | 要留下的证据与结论 |
|---|---|---|
| A01 | 经办、银行档案、法律尽调、机构报告掌握的债权和主体是否一致 | 本金息费/基准日、债务人及抵质押/保证人全称、主体关系、合同编号；四方来源和版本，不把尽调转述视为独立原件 |
| A02 | 资产事实是否一致 | 坐落、权证、权属、用途、面积、数量、完工/在建、占用/租赁、实物现状；一证多铺或一物多证的对应与面积闭合 |
| A03 | 欠付工程款及其他潜在扣减是否与“无欠付/无负担”假设冲突 | 工程款、税费、租赁保证金、安置/拆迁补偿等线索及证据；报告是肯定无欠付、资料不足未扣，还是列假设，须准确引述 |
| A04 | 报告假设与尽调/经办信息冲突是否闭环 | 先尽调记载/缺口，再报告取值依据，再原件核验，列事实—假设—参数—结果传导；不因尽调未写就否定经办线索 |
| A05 | 有依据的差异是否进入复核和建议修订 | 已核事实、仍未知金额、核实责任方、修订段落、受影响节点；未获授权不直接改机构原稿 |
| A06 | 外部成果与时点是否可靠 | 原始/转述/自动提取、基准日/期后、0/未知/未覆盖、OCR置信度、版本冲突；旧比对结论不得自动升级为事实 |

以下表格属于配套底稿或正式复核意见，不是默认叙事主文结构。主文在相关数字处解释发现，以轻量来源注释连接。

四方表最少字段：事项ID｜债权/主体/资产ID｜经办口径及出处日期｜银行原件及出处日期｜尽调记载及出处｜报告事实/假设及编号｜核实程度｜六值状态｜差异与影响｜待补与责任方。

不要只做逐字比较。先统一统计对象、基准日、单位、含息费范围；无法统一则列“口径待核”，在六值状态中用待补，不把时间差或证级/铺位级差异自动判为事实错误。某源未取得要写明，不空白暗示核验完成。经办口述可登记会谈/反馈记录日期、提供人和原话为线索，其置信度不等于合同、付款或裁判原件。

## 二、欠付工程款示例：信息怎样进入报告

假设经办反馈：“项目可能欠施工方工程款”；报告假设：“不存在欠付工程款”。这是本技能应主动识别的事实与假设差异，不能只检查乘法。

1. 找尽调中工程款、承包人、竣工验收、结算、付款、工程价款优先受偿、诉讼/执行的记载及引用资料。尽调未提，列缺口并追查经办来源；尽调只是转述时回原件。
2. 定位报告正文、特别事项、假设和计算表：是否无欠付、未获资料所以未扣、已扣、或暂列待核；追问“无欠付”的调查/确认依据。
3. 对照施工合同、工程结算/审计、付款流水、承包人确认、起诉/裁判等，分开确认：是否存在欠付、余额及截至日、是否指向本估值资产、主张主体/期限/权利效力、是否已在成本/税费中扣过。同一事项证据时点不同须解释。
4. 不从“有欠付工程款”直接推断“一定优先于抵押权”。优先性及可扣范围交法务/有效裁判核定；只有可支持的资产负担按实际模型进入扣减。金额未核，保留未知变量，不填0；没有可信范围就只给公式传导，不虚构金额区间。
5. 记录受影响资产、参数及节点，列机构需解释或修改的内容。基准模型保持报告原取值；“经核实扣减”的情景与原报告并列，避免把情景当作最终估值。

建议修订文字（按实际证据改写）：
> 根据〔经办记录/尽调/原件名称及位置、日期〕，该项目存在〔已确认欠付事实或尚待核实的工程款线索〕。原报告“无欠付工程款”假设的依据为〔报告编号/资料，或未披露〕，与现有信息存在差异。欠付余额、对应标的、权利性质及可扣范围尚待〔责任方〕核实。本复核〔不将未知金额按零确认/依据已核实资料列出条件测算〕，建议机构补充假设依据、影响范围及调整机制。

如证据已充分，把“待核”换成具体已确认事项，并列明可扣金额与依据；不得保留不适合该案的模板分支。

## 三、可比案例与最终取值互证

| 编号 | 问题 | 判断与动作 |
|---|---|---|
| C01 | 案例来源、时点、成交/挂牌/询价属性是否可验证 | 原始链接/截图/调查记录位置和日期、地址或可识别项目、出租/出售、面积与单位。匿名案例仅作为未核线索，不能视为已核成交 |
| C02 | 距离与微观区位是否可比 | 同城也可能不同市场。记录到标的距离及其测量来源/估计性质、商圈、客群、交通、临街、楼层；距离远须解释当地案例不足原因和跨区可比依据，不设统一公里阈值 |
| C03 | 交易、权利、实物与时点差异是否修正 | 成交/挂牌折让、租金含税/免租/管理费、产权/租赁期限、面积口径、装修新旧、收益时点；修正幅度方向及依据，不只写“综合考虑” |
| C04 | 案例—修正—权重—最终取值能否复算 | 每个案例原始数、修正系数/金额、调整后数值、权重及和、汇总取整、最终租金/单价；范围内取中值也须交代依据，区间外取值须解释 |
| C05 | 参数、收益/比较公式与总额是否互相支撑 | 租金/单价进入哪项计算、面积与估值明细是否闭合、报酬率/增长率/空置率是否相容；替换远距/弱证据案例的情景仅在有可靠替代依据时测算 |

案例表：标的/案例ID｜来源位置与日期｜成交/挂牌/询价｜坐落/商圈/距离依据｜业态/楼层/面积/权利｜时点与单位｜原始价格/租金｜差异与修正依据｜调整后值｜权重｜结果节点｜状态及补充解释。

有金额复算通过不意味着案例可比；案例真实也不意味着修正合理。分别报告“来源核验”“可比性判断”“计算核验”，避免一个通过替代全部。

## 四、事实—假设—参数—结论差异台账

每个差异一行：关联检查项｜原始事实及来源｜报告事实/假设及编号｜事实核实程度｜受影响资产/主体｜参数/公式节点｜原报告值｜有依据的条件值/未知｜结果影响或公式传导｜结论状态/影响等级｜建议修订文字｜待补/责任方。

未知金额且无法量化时，可按可能改变受偿路径/结论评高影响，但必须明确“潜在影响，未量化”。多个上游差异传到同一总额时，标记传播关系，不把同一数值影响重复相加。


## 五、原文层次及内部冲突

法律尽调已读与其引用的合同、流水、登记原件已逐一重查是两种范围。使用“尽调记载/律师查询时未见”，不要改写为本次直接确认全部外部事实。读取加密原件后按当前段落重新定位，不能继续用旧表转述代替原文，也不能保留过时未读声明。

对同一尽调内的借据已补/未提供、重组决议/未见展期、法代/控股股东、认缴/实缴、表内/段落金额、现场残句等，列双方位置、日期和适用对象，不能择一掩盖冲突。旧字段错属主体、日期或单位时，将旧表降为待核线索，不让它进入估值参数。

缺口必须限定证据集合：本批查册未匹配，不等于其他登记证据未取得；原始合同曾列更多抵押物，不等于当前仍全部在押。拼接登记证明、最新查册和历史至现状的解押/回款链，区分历史与现行范围。

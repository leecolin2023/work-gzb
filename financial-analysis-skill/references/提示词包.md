# 通用财报分析提示词包（v2.2）

> **使用说明**：本文件为纯指令层正本（含 `S0 / P1 / P2 / P3-Blind / P4 / P5 / P6`）。
>
> - 在 Skill 环境下：按模式路由**仅读取当前任务对应章节**；口径、规则与硬约束统一遵循 `规则与方法学正本.md` 与 `计算约束与质检手册.md`。
> - 在纯网页对话环境下：按需复制对应提示词，并在末尾附上文末「独立复制速查表」即可使用。

---

## 一、快速路由

- **材料不全先看能做啥** → `P6`
- **初筛 / 5 分钟体检** → `P2`（关闭 L3）
- **正式尽调 / 上会审批 / 高风险** → `Stage 1(脚本一键出骨架)` → `S0` → `P1(骨架填空)` → `增强 L1` → 新窗口 `P3-Blind（1+1 封顶）`
- **中小微 / 非上市主体** → 在 `P1 / P2` 末尾附加 `P4`
- **测算流贷参考额度** → `P5`

## 二、S0 · 深度任务规格重写元提示词

```text
# 任务：基于确定性门禁结果生成本案《深度分析执行规格书》（不要直接写完整报告）

## 输入材料
- 公司名称 / 行业 / 分析目的：{{公司名称}} / {{行业}} / {{分析目的}}
- 确定性门禁与指标摘要：`analysis_checks.md` + `analysis_metrics.md`（含整列留空、DQ005 与 C1–C6 结论）
- 原始表头/元数据摘录（如有）

## 执行要求
以“信贷风险识别与报表可信度穿透”为边界，把精力集中在最可能改变评级、减少重大误判或提高可验证性的地方，回答以下四个问题：

1. **顶尖信贷专家会补做什么？（隐含前提 + 翻盘检查 + 替代解释）**
   - 列出当前材料最容易被默认成立的 2–4 个隐含前提。
   - 筛选 **1–3 项最可能直接推翻 A 域（报表可靠性）或 B 域（偿债与经营风险）结论**的核查项。
   - 每项必须写清：① 检验什么假设；② 至少一种可信的正常业务替代解释或反例；③ 查到什么具体结果会直接翻盘。

2. **每条判断该查哪份“一手证据”？（按主张界定证明力）**
   - 为每项检查指定最直接、最权威的材料，定位到工作表、精确 1-based 行号（直接查 `analysis_raw_dump_index.json`）、期间、合并/单体及**时点存量 vs 期间流量属性**。
   - 明确写清该材料“**能证明什么**”与“**不能证明什么**”（严禁拿期末余额证明期间过程）。
   - 标出同源证据链，防止重复计票；缺少原件时写清替代材料、证明力缺口与需补充的原件。

3. **具体怎样查？（最小可行动作 + 冲突排查顺序）**
   - 写清每项检查的：输入 → 动作（复核基准键 vs 现场抽凭证）→ 可复查输出。
   - 遇多源数据或跨期差异，强制按序排查：`实体(合并/单体) → 版本与审计状态 → 基准日与期间(FY/H1/Q) → 科目口径 → 再处理差异`。

4. **谁或什么能独立判定结论失败？（三层外部裁判）**
   - 明确 L1（`verify_report.py --selftest` 全覆盖 + 正文 Lint）、L2（DQ/NR/口径门禁）、L3（新窗口 `P3-Blind` 1+1 封顶）各自的验收标准与推翻条件。

## 最终输出：`depth_spec.md`（紧凑精炼，≤1200 字）
1. A/B 域可分析性初判（是否满足正式评级条件，还是锁定 `NR`）
2. Top 1–3 翻盘检查项执行表（检查项 | 隐含前提 | 替代解释 | 证据定位与边界 | 执行动作 | 翻盘线）
3. 本案最易踩的 3 个失效模式预警（FM-01~FM-13）
4. 本案不可妥协的 L1 / L2 / L3 验收闸门
```

## 三、P1 · 穿透式深度完整版主提示词

```text
# 任务目标
在 `render_skeleton.py` 已生成的确定性报告骨架上，完成穿透式财务风险分析与证伪撰写，输出一份直接面向信贷尽调与风险审批的纯净专业报告。核心回答：
1. 企业资产、负债、盈利、现金流与营运效率的真实质量如何？
2. 偿债能力与压力情景下的核心风险敞口在哪里？
3. 最可能翻盘的 1–3 个风险假设是什么？有哪些正常业务替代解释？按什么一手原件核查与解除？

# 输入材料
- 已生成的报告数据骨架：`{{报告骨架路径}}`（含标准表格与防幻觉趋势/符号约束块）
- `depth_spec.md` + `analysis_checks.md` + `analysis_metrics.md` + `analysis_raw_dump_index.json`
- 原始数据元数据摘录（合并/单体、单位、审计状态、行业是否载明）

# 输出体例与纯净标题纪律（硬约束，违反任一条输出无效）
1. **开篇直入正文，严禁输出内部前置说明**：
   - 报告仅保留一级标题 `# 财务分析报告_<主体>_<期间>`，紧接着直接从 `## 1. 资产结构与资产质量` 开始；
   - **严禁输出**开篇「分析目的 / 评级纪律」等引用块；
   - **严禁输出**独立的「输入边界 / 口径登记 / 门禁轨迹 / 深度规格卡 / 执行摘要 / 企业与业务背景 / 报表可靠性与红灯扫描」章节（这些过程材料均已留痕在执行链条独立产物中，正文无需重复）；
   - **严禁输出**「三层验证边界声明」与「实际篇幅声明」小节。
2. **所有各级标题必须纯净无杂质**：
   - **严禁**在任何 `##` / `###` 标题的括号中夹带内部文件引用、校验编号、方法学提示或单位备注；
   - 禁止示例：`（2025 年末，原表定位见 analysis_raw_dump.md）`、`（C3）`、`（C2，万元）`、`（B 域）`、`（情景≠预测，缺前提不强跑）`、`（万元 / %）`；
   - 正确示例：`### 1.1 资产结构总览`、`### 1.2 核心科目六问`、`### 1.3 审慎调整反问`、`### 6.2 三情景压力测试`；
   - 金额单位、口径前提与溯源定位统一下沉至表格表头或正文说明中。
3. **固定章节结构（严格按 1–9 章输出）**：
   - `## 1. 资产结构与资产质量`（总量表、核心科目六问、审慎调整反问）
   - `## 2. 负债、资本结构与隐性负债调查清单`（总量与结构、无息负债双口径核对、隐性负债与表外事项）
   - `## 3. 盈利质量与成长性`（盈利与成长指标、利润桥与质量判断、可比增长与 CAGR）
   - `## 4. 现金流质量与回款真实性`
   - `## 5. 营运效率与营运资金`
   - `## 6. 偿债能力综合评价与情景压力测试`（偿债结构、三情景压力测试、筛查模型）
   - `## 7. 主张-一手证据-替代解释-翻盘条件核心台账`
   - `## 8. 双域独立评级与贷前/贷中/贷后动作映射`
   - `## 9. 补充资料清单与免责声明`
     - `### 9.1 最高优先级补充原件`（含拿不到原件的替代方案）
     - `### 9.2 人工复核与免责声明`（**必须逐字保留下方固定段落，不得删改**）
     - `### 9.3 Machine-Readable Summary`（JSON）
4. **`### 9.2 人工复核与免责声明` 固定段落（逐字照录）**：
   > 本报告系基于所提供的财务报表数据自动生成的辅助分析材料，仅供信贷尽调与风险研判参考，不构成审计意见、正式信用评级或授信审批结论。原始材料事实（含报表期数、留空项、科目全称、合并/单体口径、行业归属及审计意见）及正文引述的各项数值，均须由经办与审查人员结合原始凭证及底稿进行人工复核确认；任何授信评级、额度核定及风控措施的最终落地，均应以人工现场尽调与合规审批结果为准。

# 数据与风控执行纪律（违反任一条输出无效）
1. **骨架填空、数据零触碰**：
   - 仅替换骨架中的 `[待撰写：...]` 与第 7 章台账占位行，**严禁手改任何已渲染的标准表格数字**；
   - 严禁现场手写新的 Python 拼表脚本；正文引用数字一律直接抄录表格或 `analysis_metrics.json['_meta'][k]['display']`（一次舍入，严禁拿展示位相减凑 pp 或自己换算倍数）。
2. **强制服从「防幻觉约束块」**：
   - 凡涉及趋势定性（如“连续几年上升”“回落至”）与现金流方向（净流入/净流出），必须逐字核对骨架内嵌的 `> [防幻觉约束]` 块：写“净流出”时严禁带负号（写绝对值或「净额 -X 万元（净流出）」）；连升期数严格按 `末段连续上升段数` 表述；撰写完成后移除过程性 `[防幻觉约束]` 提示块，保持终稿纯净。
   - 引用原表位置一律直接查 `analysis_raw_dump_index.json` 精确 1-based 行号，禁止肉眼估行号。
3. **关键口径与证据红线**：
   - 缺必要证据（缺行业、审计或现金流）必须判对应域 `NR`，严禁凑色；行业未载明时严禁根据公司名称推定行业（任何业务背景假设均须显式标注 `[待核]`）；
   - FY/H1/Q 严禁直接同比；整列留空期严禁推定为 0 或伪倒推现金流；
   - 触发 DQ005 时严格口径指标（`核心利润（严格口径）`/`已获利息倍数（严格口径）`/严格压测）均为 `NOT_COMPUTABLE`，替代口径仅可标注 `[判断/参考]` 且注明偏低/审慎方向，严禁作为审批依据；
   - 应付票据不默认并入 DPO；现金流 `+++` 仅描述资金结构，严禁等同造假；合并科目「分配股利、利润或偿付利息支付的现金」严禁简称为「偿付利息现金」；
   - 严禁拿期末余额断言期间过程（如“期内零转固”，FM-12）；未触发红灯 ≠ 报表可靠；不把经营恶化表述为造假。
4. **高杠杆穿透与证据链去重**：
   - 优先穿透 `depth_spec.md` 锁定的 Top 1–3 翻盘检查项；
   - 第 7 章台账覆盖全部高影响主张，每条具备 `[事实]/[判断]/[待核]`、精确位置、能证/不能证边界、独立证据链编号（同源去重）、≥1 条正常业务替代解释与明确翻盘/解除条件；
   - 第 8 章双域独立评级（不合并总分）与贷前 / 贷中 / 贷后量化动作一一映射。
```

## 四、P2 · 一页纸快速穿透体检提示词（轻量模式，关闭 L3）

```text
# 任务
基于 `analysis_checks.md` 与 `analysis_metrics.md` 输出一份高密度、可证伪的一页纸财务体检结论（900–1500 字），直击最可能影响授信决策的 1–3 个核心问题。

# 输出（严格按这 7 块）
1. **材料与可分析性底线**：单位、各表有效覆盖期数（剔除整列留空）、关键缺失项、A/B 域是否具备正式评级条件（不满足必须写 `NR`）。
2. **一句话定性**：区分“证据不足 NR / 疑点偏粉饰 / 报表可信但经营承压 / 双高风险”。
3. **双域独立评级表**：A 域报表可靠性 / B 域偿债与经营风险 | 等级（含 NR）| ≤3 条带精确定位数字依据 | 证据边界。
4. **红灯去重清单**：灯号 | 信号与根因组 | 强度 | 触发值 | 正常业务替代解释 | 下一步查哪份原件。
5. **Top 1–3 翻盘级核心风险假设**：每条写清 `[事实] → [判断]（附正常业务替代解释）→ 翻盘/解除条件`。
6. **三表核心疑点各一句**：资产端 / 利润端 / 现金流端（禁拿期末余额断期间过程；缺现金流不猜正负）。
7. **最高优先级补充原件（≤5 项）** + **人工复核与免责声明**（逐字使用 P1 固定段落）。

# 硬约束
所有派生数字直接取自 `analysis_metrics.md` 一次舍入展示值，禁心算；FY/H1/Q 不直接同比；留空不作 0；触发 DQ005 禁以财务费用代利息费用下结论；`+++` 不等同造假；未触发红灯 ≠ 报表可靠；不把经营恶化说成造假。
```

## 五、P3-Blind · 独立盲审对抗裁判提示词（精简载荷 + 1+1 封顶）

```text
# 独立盲审对抗裁判任务（必须在全新无历史上下文窗口运行！）

## 运行模式（由调用方指定其一）
- **Mode A · 首轮全量盲审**（默认）：执行全部四步硬攻击，输出裁决书 `analysis_blind_review.md`。
- **Mode B · 二轮 Diff 增量复核**（仅当首轮判 `REJECT` 时触发，且全案封顶最多跑 1 次）：仅针对首轮 Reject 硬错误清单与主 Agent 提交的修改 Diff 段落做定向复核；若仍未通过，直接熔断输出 `ESCALATE_TO_HUMAN`（转人工终审），禁止第 3 轮循环。

## 精简输入载荷（无需塞入全量规则文档或超大原始表）
1. 确定性基准包：`analysis_checks.md` + `analysis_metrics.md`（含 `_meta` 趋势/符号） + `analysis_verify.md`
2. 待审报告草稿（Mode B 仅需首轮 Reject 清单 + 修改段落 Diff + 新版 `analysis_verify.md`）
3. 仅在怀疑具体科目行号或留空状态时，按需抽查 `analysis_raw_dump_index.json` / `analysis_raw_dump.md` 对应行

## 内置核心红线清单（裁决唯一标尺）
1. **双域 NR 门禁**：缺行业/审计/现金流等最小证据条件必须评 `NR`，不得强行给色；A/B 域不得合为单一总分。
2. **DQ005 阻断**：有息负债重大且财务费用>0 但利息费用缺失/为 0 时，严格核心利润/利息倍数/严格压测必须标 `NOT_COMPUTABLE`，不得拿财务费用替代口径作审批依据。
3. **FM-10 材料事实一致**：各表有效期数（剔除整列留空）、单位、审计状态、合并/单体、行业是否载明必须与基准一致，严禁凭公司名推定未载明行业。
4. **FM-12 事实边界**：严禁拿资产负债表期末存量余额断言期间过程（如“期内零转固”“从未发生”）。
5. **口径一致（FM-02）**：正文数值与口径表述必须与 `analysis_metrics.md` 真实公式一致；应付票据不默认入 DPO；合并项目「分配股利、利润或偿付利息支付的现金」不得简称为「偿付利息现金」。
6. **趋势与符号一致**：正文趋势词（如“连续 N 年上升”）与现金流净流入/净流出必须与 `analysis_metrics.md` 趋势判定一致，无双重否定。
7. **证据链去重与替代解释**：同源底稿信号须去重为 1 条独立证据链；最重 3 条风险判断均须有可信正常业务替代解释与翻盘条件；不把经营恶化写成造假，不把 `+++` 直接定性造假。
8. **L1 校验与纯净体例**：`analysis_verify.md` 必须 `fail=0`、`prose_lint_bad=0`、`self_declared_bad=0`；`uncovered > 0` 时报告正文严禁出现「全部一致/全部通过」；报告已按纯净 1–9 章体例输出且无残留 `[待撰写]` / `[防幻觉约束]` 占位块。

## 四步硬攻击（Mode A 执行全部；Mode B 仅定向复核原 Reject 项）
1. **攻击一 · 独立盲判对比**：先仅凭 `analysis_checks.md` 与 `analysis_metrics.md` 独立给出 A/B 域评级与 3 条硬依据，再与报告第 8 章比对分歧。
2. **攻击二 · 猎杀机器盲区硬伤（FM-10 / FM-12 / 口径 / 散文数）**：抽查正文段落（表格外）3–5 个关键数字与趋势表述回查 `analysis_metrics.md`；搜查时点断过程（FM-12）与越界行业推定。
3. **攻击三 · 证据链去重与替代解释压力测试**：对报告最重 3 条风险结论各构造 ≥1 条正常业务替代解释，检查报告第 7 章台账是否遗漏或重复计票。
4. **攻击四 · L1 校验真实性复核**：核对 `analysis_verify.md` 是否 `fail=0`、`prose_lint_bad=0`、`self_declared_bad=0`，且报告正文中未出现违规的「全部一致/全部通过」表述。

## 严格裁决分级（严禁过度 REJECT）
- **`REJECT`（退回修正 + 触发 1 次 Mode B Diff 复核）**：**仅当命中以下 5 类实质硬伤之一**——① 评级方向错或违规替代 `NR`；② 口径串线或数值/公式实质偏差；③ FM-12 以存量断过程或越界推定未载明行业/审计；④ 违背 DQ005 / 缺现金流伪倒推 / 覆盖率造假红线；⑤ L1 校验仍为 `FAIL`。
- **`REVISE`（主 Agent 定项修补 + 重跑 L1 通过即交付，不再二次盲审）**：无上述 5 类硬伤，仅存在行号笔误、替代解释不够充分、标题残留备注或局部措辞不够严谨。
- **`APPROVE`（直接通过，转人工终审）**：无硬伤且关键替代解释与证据边界完整。
- **`ESCALATE_TO_HUMAN`（仅 Mode B 使用）**：二轮复核仍有未解硬伤或实质分歧，强制熔断转人工终审。

## 输出裁决书结构（精简务实，≤1500 字）
1. **最终裁决**：`APPROVE` / `REVISE` / `REJECT` / `ESCALATE_TO_HUMAN`（附一句核心理由）
2. **盲判 vs 报告评级对比表**
3. **问题清单**（分级 `[硬伤-REJECT]` 或 `[修补-REVISE]` | 位置 | 违背红线 | 基准反证 | 最小必改动作）
4. **补充的正常业务替代解释（如有）**
5. **盲审自身边界声明**（仅裁决给定底稿与规则下的严谨性，不替代原始凭证抽查与现场尽调）
```

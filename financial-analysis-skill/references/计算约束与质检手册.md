# 计算约束与质检手册

> **职责边界**：本文件汇总 12 条全局硬约束、失效模式目录（FM-01~FM-13）、交付前检查清单与派生指标口径登记表模板。

---

## 第一部分：十二条全局硬约束（违反任一条 = 输出无效）

1. **分离原则**：凡涉及幂运算、开方、对数、复利或多步链式运算（周转天数 → 周转次数 → 营运资金量），必须由确定性脚本（`recalc.py`）执行；无法执行时标 `NOT_COMPUTABLE`，严禁心算或填写近似值。
2. **代入可见**：非平凡派生指标首次出现须并列「公式 / 全精度代入值 / 结果」；调整类指标（如剔除虚资产后负债率）须逐期列示。
3. **口径登记**：报告开头列「派生指标口径登记表」，全篇统一，跨期不换方法。
4. **期间对齐**：分子分母期间一致；FY / H1 / Q1 / Q3 严禁直接同比；周转天数按实际期间天数（360 / 180 / 90 / 270）。
5. **全精度链**：中间值不舍入，仅最终展示时舍入；正文声明精确值处后续不得改用近似值。
6. **局部编辑重算**：修改任一数字必须重跑完整计算链与校验，且修订记录必须同步落到正文（防 FM-13）。
7. **数量级反问**：调整类指标必须检验调整幅度是否与调整对象占资产/负债规模相称（`checks.md` C3）。
8. **方向回代**：凡引用恒等式或比率做定性推论，必须做一次方向性回代检验（`checks.md` C4）。
9. **输出侧四类自查**：定义一致性（按声明公式重算，拒以“总数闭合”替代校验，加总与倒减并列比对 C2）、数量级合理性（C3）、方向一致性（C4）、跨章一致性（`verify_report.py`）。
10. **全覆盖校验与三档判词**：校验分母必须包含报告全部可解析数值单元格（含方向未识别整表，禁静默跳过），带 `--src` 形成双基准面，核对自指统计（`self_declared_bad=0`），先跑 `--selftest` 审校验器再审报告。判词严格三档：`FULL-PASS`（fail=0 且 uncovered=0，才可写“全部一致”）；`NO-MISMATCH`（fail=0 但 uncovered>0，只能写“查到的都对”并列未覆盖清单）；`FAIL`（禁止交付）。
11. **展示位一次舍入与动态容差**：所有展示值由全精度原值一次舍入（防 FM-08）；判据为 `报告值 == round_half_up(全精度值, 展示小数位)`，采用动态容差 `0.5 × 10^(−d)`；公式代入值一律写全精度（防 FM-11）。
12. **主张级一手证据、边界与去重**：
    - 每条关键结论必须标明精确位置（文件/Sheet/行或页码/`metrics`键）及「**该证据能证明什么 / 不能证明什么**」；
    - **时点存量（资产负债表期末余额）严禁支持期间过程断言**（如“期内零转固”，防 FM-12）；
    - 同源底稿或同一底层科目衍生的多个信号只计为 **1 条独立证据链**，严禁重复计票；
    - 重要风险判断必须写明**至少一条可信的正常业务替代解释**与**明确翻盘/解除条件**。

## 第二部分：失效模式目录（FM-01 ~ FM-13）

**核心规律**：读数可靠，算数不可靠；简单除法可靠，复杂运算链、口径判断、展示精度与事实边界不可靠。当数字有现成的、看起来合理的候选值时，模型倾向于“取候选值”而非严格计算，因此唯一防线是让非平凡计算与校验脱离模型手工操作。

### 一、算术与口径类失效模式（FM-01 ~ FM-07）

- **FM-01 · 幂运算心算漂移**：`(x)^(1/n)` 无法可靠心算，错值往往顺应已有叙事而跳过直觉警报。防线：`recalc.py` + `checks.md` C4 方向一致性校验。
- **FM-02 · 口径串线（声明与执行脱节）**：声明“多科目加总”，实际执行“总数 − 某项”倒减，把性质待核科目（如长期应付款）错桶归类，甚至跨期混用两套方法。防线：C2 并列加总与倒减口径，核对差额。
- **FM-03 · 表格骨架驱动的编数**：表格某行无现成值时被叙事惯性填上“看起来略高于原值”的数字。防线：C3 数量级反推；无可靠基准一律写 `NOT_COMPUTABLE`。
- **FM-04 · 恒等式方向性误读（结论先行）**：数字算对但逻辑读反（如长期资金 > 非流动资产却误判“短债长投”；财务费用替代利息费用使分母放大、倍数偏低却误称“偏高估计”）。防线：方向回代检验 + 跨章一致性。
- **FM-05 · 跨期操作数就近取数**：比率分子分母取了不同期间（如用半年存货除以全年收入）。防线：C4 期间对齐；使用处复述期间口径。
- **FM-06 · 中间值过早舍入与分项合计漂移**：用已舍入的周转次数继续往下算，或拿已舍入分项相加代替全精度合计。防线：全程全精度计算，展示位差异显式声明而不凑平。
- **FM-07 · 局部编辑不重算**：修改单处口径或尾数后未重跑整条计算链。防线：任何数字修改必须重跑 `recalc.py` 与 `verify_report.py`。

### 二、舍入、引用与材料事实类失效模式（FM-08 ~ FM-10）

- **FM-08 · 展示位双舍入**：先舍到 2 位再舍到 1 位（如 `58.3487% → 58.35% → 58.4%`，正确为 `58.3%`），或拿已舍入的展示值参与后续加减。防线：由全精度原值一次舍入 + 动态容差 `0.5 × 10^(−d)`。
- **FM-09 · 跨列引用**：拿同年 A 口径除以 B 口径却称为“同比增长”。防线：任何同比必须可写成 `A年X口径 → B年X口径`。
- **FM-10 · 材料事实层失真**：把源表留空（未单列）说成 0、把五期说成六期、把已提供的审计意见说成未知、时间跨度表述错误（1.5 年写成 3 年）或未声明留空代入假设。防线：机器无法自动拦截，必须执行检查清单 E' 段逐条回原表核对。

### 三、复现、事实边界与修订同步类失效模式（FM-11 ~ FM-13）

- **FM-11 · 展示公式不可复现**：公式代入值填写已舍入展示值，导致读者按报告数字复算得出另一结果。防线：公式代入值一律写全精度参数，必要时附注按展示值复算的差异。
- **FM-12 · 事实边界越界（时点存量断期间过程）**：凭资产负债表期末余额不变就断言“期内零转固”“从未发生某行为”或凭三表断言“全靠借新还旧”。防线：凡关于**过程**的断言先问“手上数据是时点存量还是期间流量”，时点余额仅支持存量断言，其余一律降级为 `[待核]`。
- **FM-13 · 修订未落到正文**：修订记录表已登记更正值，但正文/表格未同步修改。防线：修订记录每条必须在同一次修改中落到正文并重跑回归校验；修订表列清「原值 / 更正值 / 差异原因 / 正文同步状态」。

### 四、跨期口径补充规则
1. **期末余额 ≠ 期间行为**（FM-12）。
2. **合并项目不得简称为其中一项**：如现金流量表「分配股利、利润或偿付利息支付的现金」未拆分股利时，不得简称为“累计利息”。
3. **替代口径方向必须回代检验**：凡存在口径替代（如财务费用代利息费用），须用公式回代确认结果偏向审慎还是乐观，避免同段自相矛盾。

### 五、校验能力对照

| 校验机制 | 拦截目标 |
|---|---|
| C2 定义一致性 / `verify_report.py` | FM-02 |
| C3 数量级合理性 | FM-03 |
| C4 方向一致性与跨章一致性 | FM-01、FM-04 |
| 全覆盖 + `uncovered` 清单 + 源表直读 `--src` | 抄错原表、源表留空误填、漏检行 |
| 同期间性质匹配 | FM-05、FM-09 |
| 动态展示精度容差 `0.5×10^(−d)` | FM-08、FM-13 |
| 全表计入分母 + `--selftest` (`INV-1 / INV-2`) | 方向盲区导致的覆盖率虚高 |
| 自指统计核对 (`self_declared_bad`) | 正文自述覆盖率与实测矛盾 |
| 人工核对清单 E' 段 + 独立盲审 `P3-Blind` | FM-10、FM-11、FM-12 及单边叙事偏见 |

## 第四部分：派生指标口径登记表模板

| 编号 | 指标 | 公式 | 依赖科目 | 适用期间 | 口径分支 / 说明 |
|---|---|---|---|---|---|
| O-01 | 资产负债率 | 负债合计 ÷ 资产总计 | 负债合计、资产总计 | 全部 | — |
| O-02 | 剔除虚资产后资产负债率 | 负债合计 ÷（资产总计 − 长期待摊费用 − 50%×在建工程） | 负债、资产、长期待摊、在建工程 | 全部 | 逐期列全精度代入值；折减率为审慎自定义口径 |
| O-03 | 资产金融负债率 | 狭义有息负债 ÷ 资产总计 | 短借、应付票据、一年内到期非流负、长借、应付债券、总资产 | 全部 | 区分狭义与广义（+长期应付款） |
| O-04 | 无息负债（加总口径） | 应付账款 + 预收/合同负债 + 应付职工薪酬 + 应交税费 + 其他应付款 + 递延收益 | 六科目 | 全部 | 跨期保持同一方法，禁止倒减替代 |
| O-05 | 速动比率（从严） | （流动资产 − 存货 − 预付款项 − 一年内到期非流动资产 − 其他流动资产）÷ 流动负债 | 多科目 | 全部 | 从严口径 |
| O-06 | 已获利息倍数 | （利润总额 + 利息费用）÷ 利息费用 | 利润总额、利息费用、财务费用 | 全部 | 触发 DQ005 时严格口径标 `NOT_COMPUTABLE`；若附注财务费用替代须注明偏低/审慎方向 |
| O-07 | 核心利润 | 营业收入 − 营业成本 − 税金及附加 − 销售 − 管理 − 研发 − 可靠利息费用 | 多科目 | 全部 | 触发 DQ005 时严格口径标 `NOT_COMPUTABLE`；研发留空期按 0 代入须声明为上限假设 |
| O-08 | 净现比 / 核心利润获现比 | 经营活动现金流量净额 ÷ 净利润（或核心利润） | 现金流量表、利润表 | 有现金流期间 | 无现金流标 `NOT_COMPUTABLE`；获现比在存货周转 <180 天时适用 |
| O-09 | 周转天数 | 实际期间天数 × 平均余额 ÷ 流量 | 多科目 | 有上年末期初的期间 | FY=360 / H1=180 / Q1=90 / Q3=270；应付票据不默认入 DPO |
| O-10 | 营运资金量 | 上年营收 ×（1 − 销售利润率）÷ 营运资金周转次数 | 营收、净利润、周转次数 | 完整年度 | 监管参考口径；周期 >720 天或项目制不适用 |
| O-11 | ROE / SGR | 净利润 ÷ 平均权益；SGR ≈ ROE × 留存收益率 | 净利润、权益、未分配利润 | 完整年度 | 非全年期 ROE 须年化后方可与全年参考对比 |
| O-12 | CAGR | （期末 ÷ 期初）^(1/年数) − 1 | 对应科目 | 可比区间 | 写明起止期与精确年数 |
| Z-01 | Z'-Score / M-Score | 见 `规则与方法学正本.md` 第三节 | 多科目 | 适用主体 | 仅作筛查信号，不作为违约或造假事实认定 |

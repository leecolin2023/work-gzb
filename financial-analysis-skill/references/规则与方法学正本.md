# 规则与方法学正本

> **职责边界**：本文件集中定义信贷财务分析的评级门禁、数据质量规则、确定性指标口径、异常信号规则、五大专业 Playbook、压力测试、决策动作映射与核心数据契约。

---

## 一、双域独立诊断与 `NR` 评级门禁

A 域（**Reporting Reliability · 报表可靠性与粉饰线索**）与 B 域（**Credit & Operating Risk · 偿债、流动性、盈利、营运与资本结构风险**）必须分开输出，不得合为单一总分。正式等级：`Green / Yellow / Orange / Red / NR`。

| 诊断域 | 正式评级最小证据条件（缺任一项原则上必须输出 `NR`） |
|---|---|
| **A 域（报表可靠性）** | ≥2 期资产负债表 + ≥1 期较完整利润表 + 现金流量表或可验证银行流水 + 报表来源或审计状态至少一项 + 至少 1 个关键异常可形成核查闭环 |
| **B 域（偿债与经营风险）** | ≥2 期资产负债表 + ≥1 期利润表 + 明确行业（行业未知仅可输出结构性风险判断，正式颜色评级原则 `NR`）+ 可靠融资成本/利息口径（如涉及利息保障）+ 现金流或明确缺失影响 |

**证据等级**：`L1 提示`（弱信号，不作减分/拒贷依据）；`L2 强烈预警`（多项独立一致强信号，须定向核查）；`L3 已证实`（有可核实外部/直接证据，仅人工复核确认后使用）。

## 三、确定性指标口径细则

- **期间天数**：`FY=360 / H1=180 / Q1=90 / Q3=270`。平均余额要求同口径同准则。
- **资本与流动性**：
  - 资产负债率 = 负债合计 / 资产总计（通用参考 45%~60%，85% 预警）；
  - 流动比率 = 流动资产 / 流动负债（参考 1.0~2.0）；
  - 严格速动比率 = (流动资产 − 存货 − 预付款项 − 一年内到期非流动资产 − 其他流动资产) / 流动负债（参考 1.0，保守 0.8，重警 <0.5）；
  - 资产金融负债率 = 有息/金融性负债 / 总资产（>50% 关注；区分狭义 vs 广义含长期应付款）；
  - 调整后负债率（剔除虚资产）/ 实质负债率（含已确认隐性负债）：仅在调整项有明确依据时计算，且须逐期展示全精度代入值。
- **盈利与成长**：
  - 核心利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 可靠利息费用（触发 DQ005 标 `NOT_COMPUTABLE`；研发留空期按 0 代入须声明为上限假设）；
  - 广义投资收益 = 其他收益 + 投资收益 + 公允价值变动收益（不含利息收入）；
  - 杜邦分解：`ROE = 净利率 × 总资产周转率 × 权益乘数`；`SGR ≈ ROE(平均权益) × 留存收益率`；CAGR 仅在可比期间计算。
- **营运效率**：
  - `DSO = 期间天数 × 平均应收(剔除已背书/保理) / 营业收入`；`DIO = 期间天数 × 平均存货 / 营业成本`；
  - **应付票据口径**：`DPO 核心口径` 不含应付票据；**仅确认属于经营性采购结算票据时**才单列 `DPO 扩展口径`；`CCC = DSO + DIO − DPO`。
- **现金流质量**：
  - 净现比 = `CFO / 净利润`（≥1 较好，<0.7 偏弱）；核心利润获现比 = `CFO / 核心利润`（存货周转 <180 天适用，1.2~1.5 良性）；销售收现比 = `销售收现 / 营业收入`；
  - **自由现金流口径**：`FCF = CFO − 维持性资本支出`，无可靠维持性资本支出数据时标 `NOT_COMPUTABLE`（若用全部购建长期资产现金近似，须显式标注近似口径）。
- **筛查模型（仅筛查，非事实认定）**：
  - **Beneish M-Score**（字段齐全且连续可比年度适用）：`M = -4.84 + 0.920·DSRI + 0.528·GMI + 0.404·AQI + 0.892·SGI + 0.115·DEPI − 0.172·SGAI + 4.679·TATA − 0.327·LVGI`，`> -2.22` 为弱预警信号（缺累计折旧置 `DEPI=1` 须标注）；
  - **Altman Z'-Score（私营非金融版）**：`Z' = 0.717X1 + 0.847X2 + 3.107X3 + 0.420X4 + 0.998X5`，`>2.90` 安全参考 / `1.23~2.90` 灰区 / `≤1.23` 预警参考（不适用于上市公司与金融机构）。

## 四、规则信号、行业例外与去重纪律

### 4.1 A 域规则（报表可靠性信号，Rules ≠ Fraud Conclusions）
| 规则ID / 简码 | 名称 | 触发条件 | 强度 | 根因组 | 下一步一手核查 |
|---|---|---|---|---|---|
| RR001 / F1 | 存贷双高 | 货币/总资产≥20% 且 有息负债/总资产≥25% | 强 | 流动性融资异常 | 受限资金、存单质押、函证、期末流水 |
| RR002 / F2 | 其他应收集中 | >10% 强；5%–10% 弱 | 分级 | 资金占用通道 | 前五大对手、关联方、账龄、用途、期后收回 |
| RR003 / F3 | 净现比偏低 | <0.70 | 弱 | 盈利现金背离 | 行业垫资周期、回款与营运资金变动 |
| RR004 / F4 | 核心利润获现不足 | 存货周转<180天：<0.50 强；0.50–1.0 弱 | 分级 | 盈利现金背离 | 应收/预付/存货占用与收现核对 |
| RR005 / F5 | M-Score 预警 | > -2.22（仅筛查） | 弱 | 模型筛查 | 拆解触发因子（重点查 TATA/DSRI） |
| RR006 / F6 | 应收增速远超收入 | 应收增速−收入增速>20% 且 应收/收入>5% | 强 | 收入确认/信用放宽 | 账龄、合同/物流/验收、期后回款 |
| RR007 / F7 | 盈利但 CFO 为负 | 净利润>0 且 CFO<0 | 强 | 盈利现金背离 | 区分扩张垫资 vs 利润虚增 |
| RR008 / F8 | 现金流组合提示 | `+++` 弱核查资金来源；`--+` 弱融资依赖；`---` 弱系统流出 | 弱 | 现金结构 | **严禁把 `+++` 直接等同存贷双高或造假** |
| RR009 / F9 | 高存货+大额减值 | 减值/总资产>5% 且 存货/总资产>30% | 中 | 资产减值质量 | 库龄、盘点、跌价依据、前期资本化 |
| RR010 / F10 | 高毛利低获现 | 毛利率>50% 且 净现比<0.80 | 弱 | 盈利现金背离 | 收入真实性与客户回款链 |

定性红旗（仅提优先级，不替直接证据）：`RQ001` 频换审计、`RQ002` 频换高管、`RQ003` 业绩精准达标、`RQ004` 复杂关联网络、`RQ005` 实控人高比例质押。

### 4.2 B 域规则（经营与偿债信号）
- `OR001 / D1` 负债率≥85%(强)；`OR002 / D2` 流动比率<1(中)；`OR003 / D3` CFO<0(中)；`OR004 / D4` Z'≤1.23(弱筛查)；`OR005 / D5` 净亏损(中)；`OR006 / D6` 严格速动<0.5(强)；`OR007` 严格速动<0.8(弱参考)；`OR008` 短借占比连期攀升(中)；`OR009` 短借+应票占流负≥80%(中)；`OR010` 净利率<3%(弱，缺行业不判优劣)；`OR011` 营运资产(应收+预付+存货)/总资产≥50%(中)；`OR012` 短债长投(中)；`OR013` 偿债现金覆盖<1.0(强)。

### 4.3 行业例外、持续性与去重纪律
- **行业参考（仅交叉验证，不作自动授信标准）**：建筑/地产/长周期白酒结构性现金流波动大，不得单凭 CFO 符号推论粉饰；项目制行业不适用标准流贷公式。实务经验参考：负债率（地产 80%+ / 钢铁 45–55% / 建筑 45–75% / 塑料 40–60% / 电子 30–50%）；存货天数（汽车 131 / 制药 356 / 建材 100 / 化工 101 / 家电 151 / 电子 95 / 日用品 62 / 商业 30）；应收天数（汽车 24 / 冶金 56 / 机加工 39 / 化工 61 / 家电 91 / 电子 90 / 食品 50 / 服装 36）。
- **持续性加权**：单期强灯降权观察，连续两期以上复现增强强度。
- **根因与证据链去重**：源于同一底层事实或同一张报表的多个高度相关指标（如垫资行业的 RR003/RR004/RR005）在综合评级前必须归并为 **1 条独立证据链**，严禁重复计票。

## 五、五大专业诊断 Playbook（仅引导调查，严禁把可能性写成事实）

1. **核心科目六问 Playbook**：对货币资金、应收账款、其他应收款、预付款项、存货、固定资产与在建工程、商誉/无形/长投、有息负债、应付票据、其他应付款、长期应付款、或有担保、权益，逐项回答：**装了什么 → 变化是否异常 → 正常业务解释 → 风险假设 → 需查一手原件 → 解除条件**。无明细只输出待核。
2. **现金流质量与八组合释义**：
   - `+ − −` 经营造血覆盖投资与偿债/分红；`+ − +` 经营造血叠加融资扩张；`+ + −` 经营与投资净流入用于还债/分红；`+ + +` 三类同正（仅说明资金净流入叠加，须查投资回收与融资用途，**不得等同造假**）；`− − −` 全面净流出；`− + +` 处置资产加筹资维持；`− + −` 处置资产偿债；`− − +` 高度依赖外部融资。
   - **缺现金流量表**：禁止以期初期末现金差额伪倒推完整三流；结合银行流水、借款变动、固定资产/在建工程、股东往来构建简易资金桥并明确标注估算边界。
3. **舞弊/可靠性七类线索**：收入（提前/总额法误用/循环交易/期后红冲）、资产（受限现金/虚增存货/在建长期挂账/占款通道）、成本费用（跨期/少提折旧/关联代垫/异常资本化）、现金流（伪装经营流入/期末冲量次年初转回/过桥空转）、表外隐匿、关联占款、治理软信息。
4. **隐性负债与表外事项**：民间借贷、小贷/保理/融资租赁、股东及关联借款、明股实债与对赌回购、对外担保圈、未决诉讼、未入表租赁、个人卡代收代付——三表无法证明其不存在，输出必须区分「已确认 / 存在迹象待核 / 无资料无法判断」。
5. **非上市/中小微适配**：多套报表动机仅作假设；无审计按 A 域门禁判 `NR`；水电/税票/订单/人数交叉验证禁用无来源经验系数；股东薪酬/私人费用调整保留账面与调整口径并列；个人敏感行为信息不得自动形成不利授信结论，合规前提下仅转人工复核。

## 六、压力测试、额度参考与贷前/贷中/贷后映射

- **三情景压力测试（情景 ≠ 预测，缺前提不强跑）**：① 收入下降 20%（写明毛利与营运资金假设）；② 核心客户流失（需客户集中度与对应应收）；③ 续贷中断（需到期分布、现金与未用承诺授信）。
- **流贷额度参考测算**：监管参考口径，非自动审批额度；项目制行业、周转周期 >720 天或基础报表不可靠时返回“不适用”。
- **三阶段决策动作（须与风险假设一一对应，弱信号禁推拒贷）**：
  - **贷前必查**：按科目调查目录（应收查账龄/前十大/合同发票物流验收/期后回款；预付查前十大/到货/关联方；存货查库龄/盘点/跌价；在建查预算/进度/转固条件/利息资本化；债务查授信明细/到期表/担保/未用额度；隐性负债查征信/流水/诉讼/担保清单）；
  - **贷中条件**：回款账户监管、受托支付、期限匹配（防短贷长投）、分期放款或结构化缓释；
  - **贷后监控**：设定可量化指标与触发线（逾期率、销售收现比、预付滚动、未来 3/6/12 月到期敞口）及触发后人工处置动作。

## 七、核心数据契约与报告结构摘要

- **标准化事实核心字段（防 FM-12 与重复计票）**：`subject, canonical_subject, statement, period, period_type(FY/H1/Q1/Q3), temporal_nature(point_in_time_stock / period_flow / policy_or_event), value, unit, scope(consolidated/standalone), source, source_locator(Sheet/行/页码), evidence_chain_id, status(reported/missing/not_applicable/derived/adjusted)`。
- **主张-一手证据-证伪台账必填字段**：`claim_id | domain | [事实]/[判断]/[待核] | claim_text | implicit_assumption | primary_evidence_required | evidence_used(精确定位) | what_evidence_proves | what_evidence_cannot_prove | evidence_chain_ids(去重) | counter_hypothesis(正常业务替代解释) | flip_condition(翻盘/解除条件) | verification_layer(L1/L2/L3) | independent_verifier`。
- **完整版报告 12 章模板**：见 `提示词包.md` P1 输出结构；文末固定保留**三层验证边界声明** + **人工复核免责声明** + **Machine-Readable Summary（JSON）**。

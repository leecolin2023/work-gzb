# 回归与验收基准

> **职责边界**：本文件定义标准回归测试用例（`CASE-001`）与迭代质量 A/B 盲评验收协议。历史实测缺陷明细与版本演进记录见根目录 `CHANGELOG.md`。

## 第一部分：CASE-001 回归基线（缺资料 + DQ005 + NR 验证）

输入：2024-12 / 2025-12 / 2026-06 标准化资产负债表，2025 FY + 2026 H1 利润表，缺现金流量表、行业、审计意见与报表来源。

### 一、基础门禁与口径行为期望
1. FY 与 H1 严禁直接同比。
2. 2026H1 利息费用 = 0 且有息负债重大、财务费用非零时，必须触发 DQ005，并将依赖可靠利息费用的严格口径指标置 `NOT_COMPUTABLE`。
3. A/B 两域正式评级均不得因缺资料强行给 Yellow/Orange，必须输出 `NR`（或明确结构性风险提示）。
4. 应付票据不得默认并入 DPO。
5. 缺现金流量表时不得推断 CFO 正负，不得虚构现金流八组合或伪倒推三流。
6. 未触发存贷双高和其他应收集中，不得写成“报表可靠”。

### 二、完整分析能力期望
1. 核心科目六问调查须覆盖：预付款、应收、存货、在建工程、长期应付款、应付票据。
2. 盈利质量输出「毛利 → 营业利润 → 利润总额 → 净利润」桥；触发 DQ005 时核心利润标 `NOT_COMPUTABLE`。
3. 现金流章节明确列出不可分析项，并优先要求补充银行流水/现金流量表。
4. 偿债分析包含隐性负债待核清单与短债长投核查（资料不足标 `[待核]`）。
5. 结论输出主张-证据-替代解释-解除条件台账与贷前/贷中/贷后动作映射。
6. `quick_scan` 简版保持紧凑篇幅，不输出完整长报告。

### 三、关键数值回归参考（容差检查，正式输出须由 `recalc.py` 计算）
- 资产负债率：约 `67.0% / 68.0% / 66.8%`
- 严格速动比率：约 `0.68 / 0.74 / 0.71`
- 短期银行借款占短+长借款：约 `57.9% / 72.2% / 75.8%`
- 2026-06 短借+应付票据占流动负债：约 `98.0%`
- 2026-06 应收+预付+存货占总资产：约 `52.3%`；加在建工程后约 `75.3%`

## 第二部分：A/B 盲评验收协议

> 目的：对提示词或规则的重大改动做可复现的对照实验，量化评估真实决策增益与增量成本。

### 1. 控制变量
- **测试集**：至少 5 份已结案或已完成人工终审的真实企业财报包（含 `CASE-001` 缺资料场景、1 份已暴露粉饰/占款案卷、1 份经营恶化但未造假案卷、1 份多期含半年/季报案卷、1 份中小微无现金流表案卷）。
- **固定条件**：同一底座模型、同一份原始资料、同一工具与脚本预算。
- **对照组 A**：基线提示词包与流程。
- **实验组 B**：候选提示词包与流程。

### 2. 复核者盲评四指标（隐藏版本与格式标识后盲评）

| 指标 | 计分口径 | 关注点 |
|---|---|---|
| **M1 · 翻盘级问题发现数** | 发现并准确界定了多少个**会真正改变 A/B 域评级或授信审批动作**的实质问题（不含凑数与假阳性） | 深度是否真正转化为决策价值 |
| **M2 · 原件可追溯且零越界率** | 抽查前 10 条核心结论，能精确追溯到原表 Sheet/行/页码且**无 FM-10 / FM-12 越界**的比例 | 一手证据纪律与事实边界 |
| **M3 · 独立复算与盲审通过率** | 经 `verify_report.py` 复算无不一致且独立盲审无硬错误的比例 | 外部确定性约束是否有效 |
| **M4 · 成本与耗时比** | 端到端耗时与总 Token 消耗；计算每多发现 1 个翻盘级问题的增量成本 | 据此决定案卷分层路由策略 |

### 3. 上线准入标准
- 实验组 B 在 M1、M2 上显著优于对照组 A；
- 实验组 B 的硬错误（FM-01~FM-13、违规评级替代 `NR`、误将经营恶化判造假）严格降为 **0**。

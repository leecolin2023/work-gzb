## 第一层：为什么不是一条制度对应一张图

本办法包含总则、适用范围、职责、操作规则、检查频率、表单及专项制度接口。原则上仅将具备独立触发—操作—输出的活动识别为流程；对定义、职责、适用边界和时限则分别映射为流程适用范围、泳道角色、判断条件和控制点。**不按条款数量直接确定图的数量**。

- 已从原文逐条抽取59个条款；将较长条款拆为191条制度原文行，便于核验具体动作和子项。
- 每个条款均能在 [01 条款—流程要素对应表](01_制度条款-流程要素对应表.csv) 找到对应的流程编码或“非绘图/全流程”标记。
- 直接写明的职责与要求作为可确认的制度依据；现行系统节点及未写明的审批授权一律记录为待核验，不以推测替代事实。

## 第二层：流程树（工作假设）

**L1 信用风险管理（暂定） → L2 授信后管理（暂定）**。此树需要与全行流程架构统筹衔接；暂不把风险管理部自动设为所有流程的主导。

| L3候选流程群 | L4工作码 |
|---|---|
| 收息收贷管理 | CL01—CL09 |
| 放款后跟踪检查 | JC01—JC02 |
| 常规检查管理 | JC03—JC07 |
| 异常风险处置 | JC08 |
| 检查报告及归档 | JC09 |
| 风险预警管理 | YJ01 |
| 资产风险分类管理 | FL01 |

这些编号为**工作码，不是行内正式编号**；流程树的级数和归属需经风险条线、公司/零售及流程管理部门调优后确认。

- 【明确主导】集团联合检查由主办行组织（第三十五条）；一手楼宇按揭项目动态检查由按揭贷款经办行开展（第四十三条）。
- 【明确执行】经营单位承担具体授信后管理、客户经理具体检查和催收，总行风险管理部统筹全行工作（第五、八、十三条）。
- 【主导待确认】部分横跨分行业务管理部门和经营单位的临期管理；放款后跟踪检查中的执行与管理；风险预警的分派、处置与解除；风险分类初分/认定/审批整体职责。
- 【外部接口】特资移交、诉讼/保全、贷款展期审批、还款交易、风险分类细则、各类产品特别规定不根据本办法擅自补写。

## 第三层：绘图和控制标注说明

当前 [03 流程图](03_授信后管理20条现状泳道图_工作草图.md) 是可直接在GitHub展示的 Mermaid **岗位泳道结构草图**，含正常/异常分支，便于业务专家逐图纠错，并非已经符合行内制图标准的WPS定稿：

1. 主线节点：制度已直接规定的业务动作及起止；判断分支附业务含义；
2. 待核节点：用浅色虚线框标出未知审批主体、外部子流程或不确定的系统活动；
3. 临时控制点：`K-流程码-XX`，在 [04 矩阵](04_风险与控制矩阵_预填草案.csv) 中可查证据与措施；
4. 相关控制表单：`S01`等为**内部工作编号**，`L01`等为清单工作编号；需验收后统一编号；
5. 线上/线下：**不在没有现场证据时进行假定**。正式WPS图按指南**黑色表示线上、红色表示线下**，使用统一制图符号及右侧注释。

WPS正式交付还应补上流程名称、适用范围、主导部门、编号版本、生效信息、适用层级、制图人与审核人等版头。最后一级流程必须有正式流程图；本项目暂将候选L4作为最后一级，待条线确认是否仍需拆L5。

## 业务核验的推荐顺序

1. **先确认流程清单与主导权**：由风险条线统筹，与公司、零售、特殊资产、审批及内控合规等核对流程边界；消除重复和遗漏。
2. **再核对真实操作**：抽查临期还贷、逾期催收、对公/零售贷后检查、预警和分类的真实业务案例；查看系统页面、流程路由、岗位权限、审批日志及纸质材料。
3. **逐项关闭[06待核问题](06_差异与职责待核实问题清单.csv)**：分别记录制度要求、实际执行、差异证据和整改建议。**当前未见真实系统证据，不能声称已经发现制度与现状的差异。**
4. **组织风险控制评估**：由业务和内控专家对矩阵43个候选控制点评估发生可能性/影响、责任与有效性，再确定哪些为关键控制点。
5. **形成正式WPS图和控制表单**：按部门确认结果重绘、评审、交内控合规/内控委验收，最终使制度、流程及系统一致。

## 特别需要对齐的业务规则

- 对公还本临期**20个工作日**提示、结息前**10个工作日**提示；分行每日查未来**3个工作日**到期的备款及结息前**5个工作日**账户情况（第十五条）。
- 对公逾期后**2个工作日内**首次催收，诉讼前至少**每季**发送催收通知（第十六条）。
- 对公首次放款后**15个工作日内**跟踪资金用途并逐笔填表（第二十九条），零售批量用途检查至少**按季**（第三十条）。
- 对公常规检查多规则取**最高频率**，季度/月度情形应按第三十四条全部列举的触发条件判断（第二十五、三十四条）。
- 个人经营贷单户授信额度**3000万元（含）以下**走小微规则，超过则走对公规则（第三十九条）。
- 个人消费/按揭类风险触发检查，**逾期10天（含）至90天（含）按月**，超过90天按需（第四十条）。
- 检查报告**15个工作日内完结签批**（第四十五条）；审批路径仍待核查。
- 资产风险分类执行**初分—认定—审批**三级程序，至少**每季**开展，重大变化及时调整（第五十二、五十三条）。

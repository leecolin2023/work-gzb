# 授信后管理SVG流程图集（V0.1）

本目录包含 **20张独立SVG泳道图**，沿用附件《征信系统用户变更申请流程图》版式：流程编号、主导部门、版本号、角色泳道、相关文件栏、任务和判断、箭头、绘制与审核信息。

**说明：** 本目录依据《授信后管理办法》和上级目录的Mermaid草图生成。角色、权限、节点线上/线下属性尚未完成业务访谈与系统验证。黑色为草图结构线，**不代表所有节点已经确认在线上**。虚线框代表需要确认的外部流程或权限。

请结合上级目录的 `01_制度条款-流程要素对应表.csv`、`02_流程分类分级清单_候选.csv`、`06_差异与职责待核实问题清单.csv` 审核。流程编号为临时工作码，正式版在审批与确认后按行内WPS符号、黑/红线规则重制。

## 先安排的补件

- **银行经办与律师**。01核一二审工程款范围。02、03、04、09核未定额先位款与逐项估值。05、08核应收账款质押登记、确权和受偿归属。06核登记顺位、租赁与处置净额。08对齐同基准日欠息台账。
- **评估机构**。逐户提交未取整逐项估价和扣减底表，说明基准日后成交、面积和业态等修正。以保证受偿为主要来源的户，逐保证人说明经营评分、净资产、在先负担和跨户分配。
- **材料可读性**。01旧版尽调文件本轮未直读，02、09尽调原件加密。三户的外部比对使用报告和二次整理线索，待可读原件复核。10泰蓝枫暂缺价值分析报告和同口径分户材料。
- **算术精度**。新增八户中03、05、08用披露输入复算，按万元保留两位时与机构相差0.01万元，待回未取整底稿。逐套抵押总额取机构披露值。
